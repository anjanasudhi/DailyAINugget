# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A single-script bot (`daily_ai_nugget.py`) meant to run once a day (via Windows Task Scheduler / cron) and deliver one bite-sized AI/ML concept explainer + a recent AI news item, generated by Claude with web search, then sent out over both email (Resend API) and Telegram (Telegram Bot API).

## Commands

```
pip install -r requirements.txt              # install deps (anthropic, python-dotenv)
python daily_ai_nugget.py --dry-run           # generate + print the message, don't send
python daily_ai_nugget.py                     # generate, send email + Telegram, advance curriculum
python daily_ai_nugget.py --topic "some topic"  # override curriculum topic selection for this run
python daily_ai_nugget.py --reset-progress    # restart the curriculum from topic 1
```

There is no build step, test suite, or linter configured in this repo.

## Configuration

All secrets/config are read from a `.env` file (via `python-dotenv`) — see `.env.example` for the required keys (`ANTHROPIC_API_KEY`, `RESEND_API_KEY`, `EMAIL_TO`, `EMAIL_FROM`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`). `.env.example` must only ever contain placeholder values — real credentials belong in `.env` only.

## Architecture

Everything lives in `daily_ai_nugget.py`, structured as a linear pipeline called from `main()`:

1. **Topic selection** (`pick_topic` / `load_progress` / `save_progress`) — `TOPIC_CURRICULUM` is an ordered, hand-curated list (not a random pool) progressing from ML foundations through classic ML, deep learning fundamentals, and modern/LLM-era topics. Each run sends exactly one topic and advances a persisted cursor in `progress.json` (`{"next_index": N}`). When the curriculum is exhausted, `LOOP_WHEN_DONE` controls whether it restarts from the top or parks on the final topic.
2. **Content generation** (`generate_nugget`) — calls the Anthropic Messages API with the `web_search_20250305` tool so Claude can find a real, currently-live tutorial link (biased toward 3Blue1Brown) and a genuinely recent news story, rather than inventing either.
3. **Delivery** — `send_email` (Resend API) and `send_telegram` (Telegram Bot API) are both called unconditionally in `main()` unless `--dry-run` is passed; both use `urllib` directly (no HTTP client dependency) and both require a `User-Agent` header to avoid Cloudflare/API bot-blocking on the request.

`sys.stdout.reconfigure(encoding="utf-8")` is set at import time because the generated messages contain emoji and the script is run non-interactively on Windows, where the default console codepage isn't UTF-8.
